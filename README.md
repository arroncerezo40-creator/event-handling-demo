# Event Handling Demo

This project demonstrates various JavaScript event handling techniques in a web browser environment.

## Features Implemented
- **DOM Access:** Using `getElementById` to interact with HTML elements.
- **Click Events:** Triggering actions via button clicks.
- **Form Handling:** Preventing default page reloads on submission.
- **Keyboard Events:** Tracking user input with `keyup` events.
- **Mouse Events:** Dynamic UI changes using `mouseover` and `mouseout`.
- **Focus/Blur Events:** Providing visual feedback when input fields are active.

## How to Run
1. Clone this repository to your local machine.
2. Open `index.html` in any modern web browser.
3. Interact with the form and buttons to see the event logs and UI updates in action.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
